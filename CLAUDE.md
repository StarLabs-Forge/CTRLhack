# Reglas de trabajo con git

- Después de CADA cambio completado, hacer commit (mensaje en español, claro y corto).
- Si el pedido incluye varios cambios, hacer un commit por cambio y un solo `git push` al terminar TODOS.
- No hacer push entre cambios de una misma tanda, solo al final.
- Commitear únicamente los archivos que se modificaron para el cambio; no incluir archivos ajenos (p. ej. `data/screenshots.json`) salvo que se pida.
